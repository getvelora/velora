# Velora Documentation

In-depth docs for running and configuring Velora. The [repo README](../README.md) is the 5-minute version; the pages
here go deeper.

- [Getting Started](getting-started.md) — first-time setup, clone to your first library
- [Configuration](configuration.md) — environment variables, container paths, SQLite and Postgres
- [API Reference](api-reference.md) — HTTP endpoints, request/response shapes, status codes
- [Troubleshooting](troubleshooting.md) — common errors and how to diagnose them

These docs version with the code — a release tag captures the docs that go with it.
